Aula 01: Variáveis

O que são, como declarar e as boas práticas no JavaScript.

O que são?

Variáveis são espaços na memória que guardam informações. Elas permitem que você armazene dados para serem usados, modificados e manipulados posteriormente pelo seu código.

Como declarar?

let

Cria uma variável de escopo local (bloco). Seu valor pode ser alterado (reatribuído) posteriormente.

let nomeDaVariavel = "valor";
const

Cria uma variável constante de escopo local (bloco). Seu valor inicial não pode ser alterado.

const nomeDaVariavel = "valor";
var

Cria uma variável de escopo global ou de função. Seu valor pode ser alterado. (Uso desencorajado no JavaScript moderno).

var nomeDaVariavel = "valor";

Diferenças e Recomendações

  • Use let para variáveis que você sabe que vão mudar de valor (ex: contadores em loops).
  • Use const por padrão para tudo. Se a variável não vai mudar de valor, ela deve ser uma constante.

Atenção: Evite utilizar var. O escopo global e o comportamento de "hoisting" do var podem causar bugs difíceis de rastrear.

Exemplos de Código

Declarando variáveis com diferentes tipos de dados primitivos e objetos:

// Declarações
let nomeCompleto = "Eric Gregorio"; // String
const idade = 20; // Number Inteiro
var altura = 1.75; // Number Float
const estaAprovado = true; // Boolean
const dataDeNascimento = new Date(); // Object (Date)

// Exibindo os valores no console do navegador
console.log(nomeCompleto);
console.log(idade);
console.log(altura);
console.log(estaAprovado);
console.log(dataDeNascimento);
